Events: paged log table (time, level StatusBadge, logger, message; expandable exception), level filter (Info/Warn/Error/All), page size 50, Refresh, newest first; never renders more than one page. Log Files: list (name, last write, size) with Download buttons and 'Open log folder' hint text with the path from system status. All pages: loading skeletons, error state with Retry, empty states.
