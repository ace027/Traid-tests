parser.ts: parseTitle(input: string): ParsedEpisodeInfo | null. Normalize: take the basename, drop a known video extension, replace '_' with spaces, keep '.' as separator. Patterns, tried in order: (1) anime '[Group] Title - 001 [..]' / 'Title - 01v2' (absolute numbers 1-4 digits, optional range '01-02'), releaseGroup from leading brackets; (2) daily 'Title.2024.03.15' / 'Title 2024-03-15' (valid date, year 1950-2100) -> isDaily, airDate; (3) multi-episode 'S01E01E02', 'S01E01-E03', 'S01E01-03' (expand ranges), 'S01E01.S01E02'; (4) standard 'S01E01', 's1e1', '1x01', 'S01 E01'; (5) season pack 'Title S01' / 'Season 1' without episode -> fullSeason true, episodeNumbers []; (6) 'Title - 101' three-digit episode only when no other pattern matched and seasons <= 9 is NOT assumed (return null instead to avoid false positives). Season 0 or 'Specials' folder -> special true. seriesTitle = text before the matched token with separators turned to spaces and trimmed; cleanSeriesTitle = lowercase alphanumerics only (drop leading 'the ', strip year in parentheses kept separately). releaseGroup = trailing '-Group' (not a known quality token, not 'DL') or anime leading bracket. quality via parseQuality. languages: default ['English'], detect 'french','german','spanish','italian','japanese','multi' tokens. Return null when no season/episode/date/absolute pattern matches. All regexes linear (no nested quantifiers, anchored token alternations). index.ts re-exports parseTitle, parseQuality and types. parser.test.ts: at least 40 table cases: standard (dotted, spaced, underscores, lowercase), 1x01, multi-episode variants, daily (dots and dashes, invalid date rejected), anime absolute with group and v2, season packs, specials S00E01, titles with years 'Doctor Who (2005) - S01E01', titles containing numbers '9-1-1 S05E01', release groups, path input '/tv/Show/Season 1/Show.S01E02.720p.mkv', non-video strings return null, and an adversarial 10k string under 50 ms.
