api.ts: loads /initialize.json once (cached promise) for apiKey and urlBase; apiFetch<T>(path, {method, body, signal}) prefixes urlBase + '/api/v3', sends X-Api-Key and JSON, parses JSON, throws ApiError {status, message, errors} for non-2xx (using the server's validation errors); helpers get/post/put/del; typed query keys factory (queryKeys.rootFolders, tags, qualityDefinitions, qualityProfiles, hostConfig, uiConfig, commands, systemStatus). events.ts: startEventStream(queryClient) opens EventSource(`${urlBase}/api/v3/events?apikey=...`), on message parses ServerEvent and invalidates the matching query key by event name (rootfolder, tag, qualitydefinition, qualityprofile, command, ... unknown names ignored), exposes useConnectionStatus() ('connecting'|'connected'|'disconnected') with exponential backoff reconnect (1s..30s) relying on EventSource Last-Event-ID; noop under jsdom when EventSource is undefined.
